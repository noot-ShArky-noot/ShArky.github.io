很多圖都能用座標法

例如：

圖形	條件
三角形	x >= mid-y
菱形	abs(x-mid)+abs(y-mid)<=n
圓形	x²+y²=r²
棋盤	(x+y)%2
X	x==y
對角線	x+y==常數
例如：畫 X
#include <stdio.h>

int main() {

    int n = 5;

    for(int y=0;y<n;y++) {

        for(int x=0;x<n;x++) {

            if(x == y ||
               x+y == n-1)

                printf("*");

            else
                printf(" ");
        }

        printf("\n");
    }

    return 0;
}
